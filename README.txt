Compact Pi1541 (Pi1581) Raspberry Pi 3A case by DeeKay64 on Thingiverse: https://www.thingiverse.com/thing:4892996

Summary:
Case for the Raspberry Pi-based cycle-exact Commodore VC1541 floppy emulator Pi1541: https://cbm-pi1541.firebaseapp.com/Things I did to the original design:Shrunk it down to Pi 3A size so it is super compact.Added an exposed USB port and a hole for the reset buttonShrunk down the LED holes to 3mm size.This is designed for the Pi1541io hat V4 with an SSD1306 128x64 display plugged directly into the I2c: https://www.hackup.net/2018/07/pi1541io-revision-4/A few minor tweaks done, like deeper screw holes etc.The green power LED is a bit fiddly with the spacers installed, but with some shrink tubing and bending pins it can be done... Make sure to get brass 10mm spacers, nylon isn't able to screw tapped into the print!Screw holes are all M2.5, and you need quite long ones for the two at the back, use a 1mm nylon washer below the spacers, otherwise they will poke out at the bottom (unless you want that!)... Also because the distance between hat and Pi is like 11.5mm! ;-)
