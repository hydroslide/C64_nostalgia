# Pi1541 case tooling

Scripts that turn the full-size Pi1541 case (`real_files/source`, built for a Raspberry Pi 3B) into cases for the
Pi Zero board whose own case is in `real_files/target`. Everything print-ready lands in `output/`.

## Layout

| Folder | What's in it | In git? |
|---|---|---|
| `real_files/` | The untouched donor STLs (source = Pi 3B case, target = Pi Zero case) | yes |
| `output/` | Print-ready STLs | yes |
| `tools/` | These scripts | yes |
| `tools/diagnostics/` | One-off probe scripts kept as a record of how numbers were measured | yes |
| `docs/renders/` | Render images used to check each revision | yes |
| `work/` | Intermediate meshes (`zup_*.stl`, assembly previews). Regenerated by the builds | no |

## Requirements

Python 3.11 with: `trimesh`, `manifold3d`, `shapely`, `numpy`, `scipy`, `matplotlib`, `rtree`, `networkx`.

```
python -m pip install trimesh manifold3d shapely numpy scipy matplotlib rtree networkx
```

On this machine Python only runs from PowerShell (the Microsoft Store build is not reachable from Git Bash).

## Builds

Each script writes its own set of files and re-reads every file it writes to confirm it is a closed solid.

| Script | Produces |
|---|---|
| `build.py` | `pi1541_zero_case_*` — first layout: board at the rear, ports/buttons on the **left** side |
| `build_rot.py` | `pi1541_zero_rot_case_*` — board turned 180°, ports/buttons on the **right** side, plus the button nubs |
| `build_bezel.py` | `pi1541_zero_case_front_1541lever.stl` — bezel with a fixed 1541-style lever |
| `build_lever_rot.py` | `pi1541_zero_case_front_1541lever_rotating_*` — bezel + 2-piece lever that actually rotates |

```
python tools\build_rot.py
```

### Knobs worth knowing (top of `build_rot.py`)

| Name | Now | What it does |
|---|---|---|
| `RAISE` | 3.5 | How far the board sits above the floor-aligned position. Raising it makes the light tunnel shallower and the encoder shaft stick out further. **Capped**: the ports must stay under the lower panel's top edge (z=-2) and below the seam. |
| `BACKOFF` | 3.5 | How far the board sits off the right wall, so the top can drop straight down past the switches. |
| `NUB_BODIES` | 1.44 / 1.94 / 2.44 | Flange lengths of the three button nubs. Set by how far the switch faces stand past the board edge (assumed 2 mm). |
| `VENT_*` | 13 grooves, 2 mm pitch | The 1541-style vent band across the rear of the top. |
| `WIN_Z` | (5, 12) | Rear window for the DIN cable, in the no-slot top. |

Sides are named as on a real drive: **front** = bezel end, **rear** = the old DIN end, **left** = the side that held
the Pi 3B's ports and buttons, **right** = the opposite side.

## Checks

```
python tools\validate_rot2.py     # rev-2 rotated: raise, nub holes, ports, vents, tunnel, assembly path
python tools\validate_rot.py      # rotated: fit, clashes, openings
python tools\validate.py          # first layout
```

They confirm the top and bottom still mate exactly as the originals did (1.03 mm³ of contact), that nothing sticks
out past the original shell, that no case material sits in the board's space, that every opening goes through, and
that the top can be lowered straight down without hitting anything.

## Versioning

The whole project is a git repo, so any released set of STLs can be brought back:

```
git log --oneline                     # history
git tag                               # released revisions
git checkout v2 -- output             # restore output/ from a tag, keeping today's scripts
git checkout <tag>                    # look at an entire old revision
git checkout master                   # back to current
```

`work/` is ignored on purpose: every file in it is rebuilt by running the scripts.
